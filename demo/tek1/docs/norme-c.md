# Norme de code de la piscine C

> Version simplifiée et fictive, écrite pour la démonstration de Sensai.

Chaque faute de norme retire des points, même si le programme marche.

## En-tête

Chaque fichier `.c` commence par cet en-tête, avec le nom du dépôt et le nom du fichier :

```c
/*
** EPITECH PROJECT, 2026
** CPool_Day04
** File description:
** my_strlen
*/
```

## Fonctions

- 20 lignes au plus dans le corps d'une fonction.
- 4 paramètres au plus.
- 5 fonctions au plus par fichier.
- Noms en `snake_case` : `my_strlen`, pas `myStrlen`.

## Boucles

Pendant la piscine, la boucle `for` est interdite : on utilise **`while`**.

## Mise en forme

- 80 colonnes au plus par ligne.
- Indentation de 4 espaces, jamais de tabulation.
- Pas de variable globale.
- Pas de commentaire dans le corps d'une fonction.
